Given the `root` of a binary tree, imagine yourself standing on the **right side** of it, return *the values of the nodes you can see ordered from top to bottom*.

---
## Test Cases
**Example 1:**

<MdxImage alt="" src="https://assets.leetcode.com/uploads/2024/11/24/tmpd5jn43fs-1.png" />
```
Input: root = [1,2,3,null,5,null,4]
Output: [1,3,4]
```

**Example 2:**

<MdxImage alt="" src="https://assets.leetcode.com/uploads/2024/11/24/tmpkpe40xeh-1.png"/>

**Example 3:**

```

```

**Example 4:**

```
Input: root = []
Output: []
```

**Constraints:**

* The number of nodes in the tree is in the range `[0, 100]`.	
* `-100 <= Node.val <= 100`
